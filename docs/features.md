# Finance Hub

*所有帳戶、所有持股、每一筆交易，都在同一個地方——而那個地方是你自己的電腦。*

銀行、信用卡、貸款、券商、退休金、台美股、加密貨幣，一個畫面看清全部身家。
數字來自你本來就會從網銀下載的對帳單，不上雲、不用帳號、不交出任何密碼。

- **完全在本機**：資料就是你電腦上的一個檔案，網頁本身連不出去
- **對帳單說了算**：照對帳單記，不估算、不猜
- **不亂換匯**：台幣歸台幣、美元歸美元，每個幣別各自一個淨值
- **匯錯救得回來**：每次匯入前自動快照，還能整批回復
- **一行指令就跑**：只要 Node 22，不用 `npm install`

## 開始

```bash
node server/index.js    # 打開 http://127.0.0.1:4321
```

只想先看看？打開 `http://127.0.0.1:4321/?storage=demo`，一本三年份的示範帳馬上出現。
每個數字都是編的，重新整理就還原。

## 主要功能

### 1. 匯入對帳單

從網銀下載 CSV，丟進來就好。

1. 把 CSV 拖進「匯入」頁
2. 自動認出格式；還沒有帳戶的話，連帳戶都幫你建好
3. 看一眼預覽，按「匯入」

重複的不會再匯進來。已支援玉山、BoA、Chase、Citi、Capital One、Firstrade、
Fidelity 401(k)，其他銀行手動對應欄位也能匯。

### 2. 總覽：一眼看清淨值

1. 打開就是總覽，每個幣別一個淨值、一條走勢
2. 切換「可動用／受限制／全部」，退休金這類動不了的錢分開看
3. 「待辦」列出要處理的事，一鍵帶你過去

### 3. 帳對得上

1. **轉帳配對**：系統找出自己轉給自己的錢，勾選配對，就不會被算成收支
2. **對帳**：填網銀上看到的餘額，系統告訴你差多少
3. **完整度**：帳戶 × 月份的格子，哪個月沒匯一眼就看到

### 4. 消費分析

1. 每月支出、分類佔比，一頁看完
2. 訂閱和月繳自動認出來，列成「固定扣款」
3. 設幾條分類規則（例如 `UBER EATS` → 外食），之後匯入自動分類

### 5. 持股

1. 新增持股：台股、美股或加密貨幣，填代號、股數、成本、現價
2. 市值、損益、配置一頁看完
3. 想省事就在設定打開「自動更新收盤價」（預設關閉）
