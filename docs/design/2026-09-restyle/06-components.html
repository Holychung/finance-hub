焦點環：目前完全沒有
現在 input:focus { outline: none } 把輸入框的系統焦點框拿掉，只換成一個幾乎看不見的邊框變色（#4a5878 對 #2e3750）；按鈕和連結則一個焦點樣式都沒有。只用鍵盤時，Tab 到哪裡是看不出來的。

改成統一一條規則：:focus-visible { outline: 2px solid var(--brand); outline-offset: 2px }，套在按鈕、連結、輸入、checkbox、表格內的圖示鍵上。用滑鼠點不會出現，只在鍵盤操作時出現。
