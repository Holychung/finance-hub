## 提案的三條規則

這三條後來寫進了 `CLAUDE.md`，是整次改版的依據：

1. **綠與紅只屬於金額。** 原本 `--accent` 同時是品牌色（主按鈕、側欄、圖表線）和「這個數字是正的」，所以「可以點」和「賺了」長得一樣；`.danger` 又跟 `.neg` 同一個紅，讓紅色刪除鍵站在一整欄紅色數字旁邊。
2. **帳本是紙。** 這條的淺色版本被否決了，但它背後的意思留下來了：密集的數字表要靠高對比和克制的用色，不是靠儀表板式的裝飾。
3. **每個顏色都算過。** 圖上每一格都標了對比值。當時的 `--text-3` 是 3.68:1（表頭和所有次要文字都在用）、滑過整列 1.03:1、輸入框邊框 1.64:1。

## 這些檔案是怎麼來的

canvas 的 `.dc.html` 只能在那個編輯器裡算圖——它需要一份 3.3MB 的 runtime 來解釋 `<x-dc>`、`<helmet>` 和邏輯區塊。原樣存進來等於存了六個沒人打得開的檔案。

六張圖全部是帶 inline style 的靜態 markup（沒有樣板變數、沒有迴圈、沒有子元件），所以拆掉外層不會損失任何東西：把 `<helmet>` 裡的 CSS 移進 `<head>`、丟掉 runtime 的 `<script>`、留下內容本身。匯出腳本在拆之前會檢查有沒有動態語法，有的話直接中止而不是默默產生壞掉的頁面。
